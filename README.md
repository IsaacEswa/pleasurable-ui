- De navigatielinks bevatten hover- en active-states. De hover-state geeft feedforward doordat zichtbaar wordt dat de links interactief zijn. De active-state geeft feedback over welke pagina actief is.

https://github.com/user-attachments/assets/81ab07d8-4c76-4448-b9f2-e44fe80a188c

- Het hamburgermenu bevat een animatie waarbij het icoon verandert naar een kruis wanneer het menu geopend wordt. Dit geeft feedback dat het menu actief is en feedforward dat het menu ook weer gesloten kan worden.

https://github.com/user-attachments/assets/081c0ab9-a71d-418f-bce7-c9d1aea7f99b

- De website bevat een custom 404 error state. Wanneer een gebruiker een niet-bestaande pagina bezoekt, krijgt de gebruiker duidelijke feedback via de foutpagina en een button om terug te navigeren naar de homepage.
  
- Op de 404-pagina bevat de button een hover-animatie waarbij de achtergrondkleur donkerder wordt en de button licht vergroot met een scale-animatie. Dit geeft feedforward dat de button klikbaar is en feedback tijdens de interactie.

https://github.com/user-attachments/assets/b09142a6-299d-4ef8-b58e-e3d6fb50e624
