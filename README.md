### Filter en Sorteren
Op de districtenpagina is er boven in een filter en sorteer section. Er kan gefilterd worden per Doelgroep en gesorteerd op Oud-Nieuw, Nieuw-Oud en A-Z.

<img width="775" height="69" alt="image" src="https://github.com/user-attachments/assets/5eed8e13-4bbb-4f73-969d-23260044750f" />
<img width="232" height="113" alt="image" src="https://github.com/user-attachments/assets/632d5cf8-d6d5-4e85-8eeb-3f4161dbd34f" />



Er is een hover state aanwezig. Gekenmerkt door een lichtere oranje kleur. En verder is er ook een active-state, gekenmerkt door de paarse kleur. De non-actieve fileters hebben een oranje kleur, om ze te onderacheiden van de actieve fileter. Deze twee kleuren zijn gekozen omdat het de meest herkenbare en meest terugkerende kleuren zijn.
